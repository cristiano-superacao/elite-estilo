# Elite & Estilo

## Dependências e Setup

### Local Development
```bash
npm install
npm run dev
```

### Build para Produção
```bash
npm run build
npm run preview
```

## Deploy

### Netlify
- Build command: `npm run build`
- Publish directory: `dist`
- Node version: 18+

### Variáveis de Ambiente
Não há variáveis de ambiente necessárias para este projeto.

## Estrutura do Projeto

- `/src/components/ui/` - Componentes UI reutilizáveis
- `/src/pages/` - Páginas da aplicação
- `/src/assets/` - Imagens e recursos estáticos
- `/src/lib/` - Utilitários e helpers

## Tecnologias

- React 19
- React Router DOM
- TailwindCSS 4
- Framer Motion
- Lucide React
- Vite 6
