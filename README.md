# Elite & Estilo

Sistema de gestão completo para barbearias e salões de beleza, desenvolvido com React, TailwindCSS e tecnologias modernas.

🌐 **Site:** https://elitestilo.netlify.app
📱 **GitHub:** https://github.com/cristiano-superacao/elite-estilo

## 🚀 Funcionalidades

✅ **Carrossel na Página Inicial** - 3 slides com autoplay e controles  
✅ **Página de Planos** - 4 opções de planos com destaque visual  
✅ **Seção de Salões** - Cards com avaliações, serviços e agendamento  
✅ **Seção de Promoções** - Ofertas especiais com descontos  
✅ **Navegação Responsiva** - Header fixo e menu mobile  
✅ **Footer Completo** - Links rápidos e informações de contato  

## 🛠️ Tecnologias

- React 18
- React Router DOM
- TailwindCSS 3
- Framer Motion
- Lucide React
- Vite 6
- Node.js 20

## 📋 Dependências e Setup

### Desenvolvimento Local
```bash
npm install
npm run dev
```

### Build para Produção
```bash
npm run build
npm run preview
```

## 🚀 Deploy

### Netlify (Automático)
- Build command: `npm run build`
- Publish directory: `dist`
- Node version: 20

### GitHub Actions
Deploy automático configurado no push para `main` branch.

### Variáveis de Ambiente
```bash
NEON_DATABASE_URL="postgresql://usuario:senha@ep-endereco.neon.tech/db"
NODE_ENV="production"
```

## 📁 Estrutura do Projeto

- `/src/components/ui/` - Componentes UI reutilizáveis
- `/src/pages/` - Páginas da aplicação
- `/src/assets/` - Imagens e recursos estáticos  
- `/src/lib/` - Utilitários e helpers
